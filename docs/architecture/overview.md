# Genel Mimari

Platform Hexagonal (Clean) Mimari + Domain-Driven Design ile inşa edilmiştir.

## Katmanlar

1. **Exchange Gateway** — Salt okunur borsa adaptörleri
2. **Market Data** — Veri normalizasyonu ve feature store
3. **ML / RL** — Model eğitimi, tahmin ve sürekli öğrenme
4. **Strategies** — Ensemble, Meta-AI, Genetik Algoritma
5. **Simulator** — Paper trading motoru
6. **Risk** — Bağımsız, imzalı risk limitleri
7. **Analytics** — Backtest, metrikler, raporlama
8. **API / Dashboard** — FastAPI + React
