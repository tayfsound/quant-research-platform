# Kod Standartları

- Python: ruff (E, F, I, N, W, UP, SIM), line-length 120
- TypeScript: ESLint + Prettier
- Dosya başına maksimum 1000 satır, sınıf 300 satır, metot 40 satır.
- Tüm fonksiyonlar tip ipucu içermeli.
- Asenkron kod tercih edilmeli (async/await).
- Veritabanı sorguları repository pattern üzerinden yapılmalı.
- Gizli bilgiler Config sınıfı üzerinden, çevre değişkenleri ile sağlanmalı.
